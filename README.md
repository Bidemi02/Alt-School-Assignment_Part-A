# Alt-School-Assignment_Part-A
My first assignment contains page and a new web page with a form that mirrors the AltSchool Africa sign-in page. The two pages are connected through a global navigation bar at the top of each page.

•   Features
Global navigation at the top of both pages, linking index.html and form.html
Sign in form with email, password, show-password checkbox, "Proceed to Dashboard" button, "Reset Now!" link and a Continue with Google button
Sign up and password reset sections
Footer with an address and copyright notice on both pages
No CSS: the pages use browser default styling only


•   Accessibility
Semantic HTML tags: header, nav, main, section, form, fieldset, address, footer
Every input has an associated <label>
"Skip to main content" link at the top of each page
aria-label on navigation landmarks and aria-current on the active link
Appropriate input types (email, password) and autocomplete attributes


•   How to Run
Download or clone this folder.
Make sure index.html and form.html are in the same folder.
Open index.html in any web browser and use the navigation bar to move between pages.
